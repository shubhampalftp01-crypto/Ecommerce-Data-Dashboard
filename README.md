# 🛒 E-Commerce Analytics Dashboard 🇧🇷

## 📌 Project Overview
An end-to-end, Full-Stack E-Commerce Data Analytics Dashboard. This project demonstrates the complete data engineering lifecycle: migrating raw data into a relational database, executing SQL queries, and deploying an interactive frontend for business intelligence.

## 🛠️ Tech Stack
- **Frontend / UI:** Streamlit (Python)
- **Backend / Database:** SQLite (Relational Database)
- **Data Manipulation:** Pandas
- **Data Visualization:** Matplotlib, Seaborn

## 🚀 Key Features
- **Database Engine:** Data is dynamically fetched using optimized SQL `JOIN` operations from a local SQLite database.
- **📈 Revenue Engine:** Monthly revenue trend analysis to track business growth.
- **🚚 Delivery Performance:** Distribution of delivery times (in days) to measure operational efficiency.
- **📍 Customer Hotspots:** Visualizing the top 10 cities generating the most orders.
- **💳 Payment Methods:** Pie chart breakdown of preferred customer payment types.
